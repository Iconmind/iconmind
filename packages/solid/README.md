# @iconmind/solid

SolidJS components for [IconMind](https://iconmind.dev) — 3,287 tree-shakeable icons
for AI-era software: LLMs, agents, MCP, RAG, and everything around them.

```bash
npm i @iconmind/solid
```

```tsx
import { Agent, ContextWindow } from "@iconmind/solid";

<Agent />
<ContextWindow size={32} />
```

Docs & search: [iconmind.dev](https://iconmind.dev) · MIT.
