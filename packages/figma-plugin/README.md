# IconMind for Figma

Search the whole set inside Figma and drop any icon on the canvas as a vector — outline or
duotone, thin/regular/bold, at 16–48 px. The plugin loads the set from the published
`@iconmind/icons` package on jsDelivr, so it is always the current release and weighs
nothing itself.

## Run it locally

Figma → Plugins → Development → *Import plugin from manifest…* → this folder's `manifest.json`.

## Publish

Plugins → Development → the plugin → *Publish*. Name **IconMind**, tagline *2,271 open-source
icons for AI-era software — agents, MCP, RAG and every interface family*, cover from
`.github/assets/preview-light.png`, link https://iconmind.dev. MIT, like the icons.
