# @iconmind/icons

1,008 SVG icons for AI-era software — LLMs, agents, MCP, RAG, and everything around
them. The raw set: plain SVGs, metadata, and a sprite. No framework required.

Every icon ships in six cells: **outline** and **duotone**, each at **thin / regular /
bold** (1.5 / 2 / 2.5 stroke).

```bash
npm i @iconmind/icons
```

```js
// one file per cell
import agent from "@iconmind/icons/icons/agents/agent/outline-regular.svg";

// metadata for search and tooling
import metadata from "@iconmind/icons/metadata.json";
```

Docs & search: [iconmind.dev](https://iconmind.dev) · React components:
[`@iconmind/react`](https://www.npmjs.com/package/@iconmind/react) · MIT.
