# @iconmind/preact

Preact components for [IconMind](https://iconmind.vercel.app) — 1,041 tree-shakeable icons
for AI-era software: LLMs, agents, MCP, RAG, and everything around them.

```bash
npm i @iconmind/preact
```

```tsx
import { Agent, ContextWindow } from "@iconmind/preact";

<Agent />
<ContextWindow size={32} />
```

Docs & search: [iconmind.vercel.app](https://iconmind.vercel.app) · MIT.
