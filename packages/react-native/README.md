# @iconmind/react-native

React Native components for [IconMind](https://iconmind.dev) — 2,387 tree-shakeable
icons for AI-era software, rendered with `react-native-svg`.

```bash
npm i @iconmind/react-native react-native-svg
```

```tsx
import { Agent, ContextWindow } from "@iconmind/react-native";

<Agent color="#111" />
<ContextWindow size={32} />
```

Docs & search: [iconmind.dev](https://iconmind.dev) · MIT.
