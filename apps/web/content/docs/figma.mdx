## The plan

One Community file, not one per category — designers install a library, not twelve.
Components organised by domain, named `category/slug` so Figma's own grouping does the
work, with the description field carrying the same tags the site searches on.

## Generated, never redrawn

The file will be built from the SVG in this repository by a script. Redrawing icons in
Figma would create a second source of truth, and the two would diverge within a month —
that is the same reason no component files are committed in the packages.

## Why it matters

Figma is where a lot of icon decisions actually get made, before any code is written. It
is also the channel with the longest tail: a post on Hacker News is dead in two days,
while a Community file keeps being found through Figma's own search for years.

Until then, every icon page here has a copy button for the raw SVG, which pastes straight
into Figma.
