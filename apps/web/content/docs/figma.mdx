There is no IconMind plugin or Community library, and none is planned. There are three
ways to use the set in Figma that work now and need nothing from us.

## The Iconify plugin

The set is published as an [Iconify](https://iconify.design) collection, and Iconify's
own Figma plugin reads every collection. Install it, search `iconmind`, and insert any
icon as a vector — outline or duotone.

```text
iconmind:agent            outline
iconmind:agent-duotone    duotone
```

## Copy the SVG

Every icon page has a copy button and a **Download** menu — SVG at the variant, weight
and colour on screen, and PNG, WebP or a favicon if you need a raster. SVG pasted into
Figma arrives as a vector with editable strokes.

## Drag the whole set in

The [set as a zip](https://github.com/Iconmind/iconmind/releases) — `iconmind-svg.zip` on
every release — is one folder per icon, six files each. Drag any of them into a Figma
file and they land as vectors; drag a folder in and Figma imports the lot.

## Why there is no library file

A Figma library would be a second source of truth. The drawings in this repository are
compiled — every cell is generated from one declaration and checked by a validator — and
a hand-maintained Figma file would diverge from them within a month. Iconify already
carries the same generated output, updated with each release, which is the same thing
without the drift.
