## What is IconMind?

An open-source set of more than five thousand SVG icons for software built around AI.
Over nine hundred are for LLMs, agents, RAG and MCP; the rest cover the devops, data,
security and interface work around them, plus everyday domains such as commerce and
travel. Every icon comes in outline and duotone, in three weights, on a 24px grid. MIT
licensed.

## Which frameworks does it support?

Components for React, Vue 3, Svelte, Solid, Preact, React Native and Astro on npm, and
for Flutter on pub.dev. Plain SVG files and a sprite come from `@iconmind/icons`. The
[installation page](/docs/installation/) has the package name and install command for
each.

## Can an AI coding assistant use it?

Yes. `@iconmind/mcp` is an MCP server that searches the set and answers with names that
exist, so an assistant stops inventing icon names that do not. In Claude Code:
`claude mcp add iconmind -- npx -y @iconmind/mcp`. The [MCP page](/docs/mcp/) covers
other clients. For an assistant reading the web, [llms.txt](/llms.txt) lists every icon.

## Can I use these commercially?

Yes. MIT, code and icons alike. No attribution, no conditions, forever. That is stated
plainly because every extra condition is a reason for someone's legal team to pick a
different set — and that decision happens without us ever hearing about it.

## Why not just contribute to Lucide?

Nine hundred domain-specific AI icons is scope creep for a generalist set, and it should
be. IconMind is built to sit next to those sets, not replace them — the 24px grid and 2px
stroke match deliberately so both can appear in one interface without clashing.

## Icons drawn with AI — isn't that slop?

Every icon passes an automated validator and a human review, and roughly seven of eight
candidates are thrown away. The rules and the validator are in the repository; you can
read exactly what is enforced.

The honest version: AI moved the bottleneck from drawing to judging. Judging is still the
slow part, and it is still done by a person.

## Will there be a solid variant?

No. The set's language is open silhouettes — shapes that stop short of closing — and a
shape with no inside cannot be painted into anything but a band as wide as the stroke that
drew it. Three separate engines were built to derive one, and all three produced cells that
either read identically to the outline or came out broken. Duotone carries the weight that
a solid variant would have carried.

## What if the project stops?

MIT, no backend, no accounts, no telemetry. Whatever you have installed keeps working
forever, and the repository can be forked by anyone.

## Why not add icons faster?

Because the alternative is worse. A thousand mediocre icons is not more useful than a
hundred good ones — it is harder to search and harder to trust. The set grows at the rate
a person can actually review it.

## An icon I need is missing

[Request it.](https://github.com/iconmind/iconmind/issues/new?template=icon-request.yml)
Requests and searches that return nothing are what decide the next batch.
